# maps-to-tesla 使い方

導入（[SETUP.md](SETUP.md)）が済んだあとの、日常の使い方です。

## 1. iPhone ショートカットから送る

1. Google Maps でルート（経由地つき）を作ります
※Gemini等に旅行プランを作ってもらい、そのGoogle MapsリンクもOK
2. 共有 → 「Teslaへ送る」

ショートカットの作り方は SETUP.md のステップ 7（任意）です。

## 2. ブラウザのページから送る

1. `http://<コンテナのアドレス>:8765/` を開きます
2. Google Maps の共有リンクを貼ります
3. **「経由地のまま送る」** を押します
4. 名前だけの地点が含まれる場合はどの場所として 送るか）が表示され、
ボタンが **「この内容で送信する」** に変わります。
内容を確認して、もう一度押すと送信されます
5. 成功すると、送信した経由地の並びが表示されます。車のナビに
 その順番で設定されます（経路と充電計画は車側で再計算されます）

## 地点の扱い

- **名前だけの地点**: 近くにある同名の場所を探して送ります。
  見つからなければ送信せず、エラーで知らせます
- **座標だけの地点**: 近くにある登録済みの場所（施設や店）に
  寄せて送ります。100 m 以内に場所が無い地点は送信から外し、
  結果に「※外しました」と明記します。**自宅のように、場所として
  登録されていない地点の座標は、近くに場所が無いため送信から
  外れます**（住所そのものは Google にあっても、座標の場合は
  住所ではなく場所を探す仕組みです）。その場合は、自宅そのもの
  ではなく近くの施設を目印の地点にしてください
- **住所をそのまま書いた地点**: 住所の Place ID が取得できた
  場合のみ送れます。取得できないこともあります

## うまくいかないとき

- **「送信できませんでした」/「車への送信に失敗しました」**
  車が起きなかった、または通信が混んでいた可能性があります。
  1 分ほど置いてから、もう一度送ってください。起床の呼び出しは
  1 分に最大 2 回までに自動で抑えているので、続けて何度も
  送っても速くはなりません
- **名前が解決できないというエラー**
  Google Maps 側で、その地点を住所や座標ではなく、場所として
  登録された地点（ピン）に置き換えてから送り直してください
- **`login_required`&#32;/&#32;`The refresh_token is invalid`**
  ログイン情報の失効です。`/setup` のステップ 4 から
  再ログインしてください
- ページ下部の **「最近の実行時間」** に、送信ごとの内訳
  （どこで時間がかかったか）が残ります。失敗したときの
  切り分けに使えます

## 注意

- 運転中は操作しないでください。送信は停車中か、同乗者に
  お願いしてください
- 送信後は、車のナビで経由地が正しく設定されたか
  確認してください
- 送信のたびに車を起こすため、Fleet API の従量課金が
  かかります。起床は 1 回 $0.02 で、月 $10 分の無料クレジットは
  起床だけなら約 500 回分あります。送信 1 回にかかるのは
  起床とわずかなコマンド料だけなので、通常の使い方であれば
  無料の範囲に収まり、費用はかかりません
  （ただし保証はできません）
